What the check actually tests (posebusters 0.6.5)
  • Only 6-membered non-aromatic rings with 0–2 double bonds (cyclohexane, cyclohexene, the cyclohexadienes, piperidine, piperazine, morpholine, dihydropyridines). The 5-ring pattern is commented out upstream, so a flat cyclopentane or pyrrolidine can never fail it. The 5-ring table below applies the same threshold anyway.
  • A ring passes if at least one atom sits ≥ 0.05 Å from the ring's best-fit (SVD) plane.
  • The distance is signed: PoseBusters takes max(d), not max(|d|), and the SVD normal's sign is arbitrary. So a ring bent to one side only can fail with |d| = 0.08 Å. Statuses here: fail fails for both signs · sign-dependent fails for one sign only · pass passes for both signs.
  • MMFF overlay: the same molecule minimised with MMFF (UFF when MMFF has no parameters), starting from the generated pose and superposed on the ring atoms. If the relaxed ring is also under 0.05 Å, the force field wants it flat too.
